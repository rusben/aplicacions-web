Guia: instal·lar Nextcloud

Nextcloud sobre Apache, MySQL i PHP, amb les dades fora del web i les tasques en segon pla en marxa.

Què hi ha en aquesta guia

Documentació oficial: Installation · requeriments del sistema

  • Punt de partida: un escriptori d'IsardVDI amb Ubuntu a punt (G1.1) i la pila LAMP de G1.2.
  • Resultat: Nextcloud a http://nuvol.internal, amb les dades a /var/ncdata i el cron cada cinc minuts.
  • La base de dades es diu ncdb i l'usuari ncuser.
Primer, els requeriments Nextcloud admet unes versions concretes de PHP. Mira la pàgina de requeriments de la versió que baixis i compara-la amb php -v. Si la versió d'Ubuntu de l'escriptori porta un PHP massa nou, fes l'escriptori amb la versió anterior d'Ubuntu i canvia el número a les rutes de /etc/php/… d'aquesta guia.

Preparar el servidor

  1. Instal·la la pila i les extensions que demana Nextcloud:

    sudo apt update
sudo apt install -y apache2 mysql-server libapache2-mod-php \
  php-mysql php-gd php-curl php-mbstring php-intl php-xml \
  php-zip php-bcmath php-gmp php-imagick unzip

  2. Puja els límits de PHP: els fitxers grans i les miniatures ho demanen.

    sudo nano /etc/php/8.5/apache2/conf.d/99-nextcloud.ini
    memory_limit = 512M
upload_max_filesize = 2G
post_max_size = 2G
max_execution_time = 3600
output_buffering = Off

  3. Activa els mòduls d'Apache que necessita i reinicia:

    sudo a2enmod rewrite headers env dir mime
sudo systemctl restart apache2

  4. Crea la base de dades i el seu usuari:

    sudo mysql
    CREATE DATABASE ncdb
  CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER 'ncuser'@'localhost' IDENTIFIED BY 'Canvia-la-2026';
GRANT ALL PRIVILEGES ON ncdb.* TO 'ncuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Posar-hi el codi i el directori de dades

  1. Baixa i descomprimeix l'última versió:

    cd /tmp
wget https://download.nextcloud.com/server/releases/latest.zip
sudo unzip -q latest.zip -d /var/www
sudo mv /var/www/nextcloud /var/www/nuvol.internal

  2. Crea el directori de dades fora de l'arrel web. És el punt més important de la instal·lació:

    sudo mkdir /var/ncdata
sudo chown -R www-data:www-data /var/ncdata /var/www/nuvol.internal
sudo chmod 750 /var/ncdata

  3. Comprova l'espai del disc on aniran els fitxers:

    df -h /var/ncdata

Host virtual i instal·lador web

  1. Escriu el host virtual:

    sudo nano /etc/apache2/sites-available/nuvol.internal.conf
    <VirtualHost *:80>
    ServerName nuvol.internal
    DocumentRoot /var/www/nuvol.internal

    <Directory /var/www/nuvol.internal>
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/nuvol.internal_error.log
    CustomLog ${APACHE_LOG_DIR}/nuvol.internal_access.log combined
</VirtualHost>

  2. Activa'l i resol el nom:

    sudo a2ensite nuvol.internal.conf
sudo apache2ctl configtest
sudo systemctl reload apache2
echo '127.0.0.1 nuvol.internal' | sudo tee -a /etc/hosts

  3. Obre http://nuvol.internal i omple l'assistent: compte d'administrador, carpeta de dades /var/ncdata, i MySQL amb ncdb, ncuser i la contrasenya.

  4. Espera que acabi la instal·lació de les aplicacions recomanades i entra al tauler.

Tasques en segon pla i accés des d'una altra màquina

  1. Programa el cron amb l'usuari d'Apache, cada cinc minuts:

    sudo crontab -u www-data -e
    */5 * * * * php -f /var/www/nuvol.internal/cron.php

  2. Tria «Cron» com a mètode a Configuració → Paràmetres bàsics. Si hi diu que fa massa estona que no s'executa, revisa la línia anterior.

  3. Autoritza el nom o la IP amb què s'hi entrarà des d'una altra màquina. Des de la carpeta del lloc:

    cd /var/www/nuvol.internal
sudo -u www-data php occ config:system:get trusted_domains
sudo -u www-data php occ config:system:set \
  trusted_domains 1 --value=192.168.120.45

  4. Prova-ho des d'un altre escriptori de la mateixa xarxa: http://192.168.120.45 ha de demanar l'inici de sessió.

La consola d'administració

L'ordre occ fa des del terminal el que es fa al tauler, i coses que només es poden fer així. S'executa sempre com a www-data i des de la carpeta del lloc.

OrdreFa
occ statusVersió i estat de la instal·lació
occ user:list · occ user:addComptes
occ group:listGrups
occ files:scan --allTorna a llegir els fitxers i refà l'índex
occ app:list · occ app:enable nomAplicacions
occ maintenance:mode --onManteniment, per fer còpies

Còpia i restauració

  1. Posa el servei en manteniment i fes la còpia de les dues meitats:

    cd /var/www/nuvol.internal
sudo -u www-data php occ maintenance:mode --on
sudo mysqldump --single-transaction ncdb > ncdb-$(date +%F).sql
sudo tar -czf nc-$(date +%F).tar.gz \
  -C /var/www nuvol.internal -C /var ncdata
sudo -u www-data php occ maintenance:mode --off

  2. Treu la còpia del servidor cap a un altre escriptori:

    scp ncdb-*.sql nc-*.tar.gz usuari@192.168.120.46:~/copies/

  3. Per restaurar, desfés els dos fitxers i torna els permisos:

    sudo tar -xzf nc-DATA.tar.gz -C /
sudo mysql ncdb < ncdb-DATA.sql
sudo chown -R www-data:www-data /var/www/nuvol.internal /var/ncdata

Comprovació de conjunt

  • curl -I http://nuvol.internal respon i porta a l'inici de sessió.
  • curl -I http://nuvol.internal/../ncdata no dona cap fitxer: les dades són fora de l'arrel web.
  • sudo -u www-data php occ status diu installed: true i la versió.
  • A Configuració → Visió general no hi ha avisos de seguretat ni del cron.
  • Des d'un altre equip de la xarxa, l'adreça autoritzada obre el servei.

Criteris professionals

  • Les dades, sempre fora de /var/www.
  • occ com a www-data: executar-lo com a root deixa fitxers que Apache no podrà escriure.
  • Cron de sistema, no les tasques per AJAX: és l'únic mètode fiable.
  • Quota per defecte per als comptes nous.
  • Una còpia amb el servei en manteniment, i provada.

Errors habituals

«Access through untrusted domain»

Causa S'hi entra per una adreça que no és a trusted_domains.

Solució Afegeix-la amb occ config:system:set, com al pas anterior.

La visió general avisa que el cron no s'executa

Causa La línia del cron té una ruta equivocada o no és de www-data.

Solució Executa-la a mà i mira l'error: sudo -u www-data php -f /var/www/nuvol.internal/cron.php.

No es poden pujar fitxers grans

Causa Els límits de PHP són baixos.

Solució Revisa el fitxer de conf.d del pas 2 i reinicia Apache.

Els fitxers copiats per SSH no surten al navegador

Causa No són a l'índex del servei.

Solució sudo -u www-data php occ files:scan --all.
