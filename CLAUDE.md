# Instrucciones para Claude

Antes de editar, consulta `GUIA.md`. Al trabajar con páginas HTML, aplica
también `.claude/rules/redaccio.md`.

- Habla con el usuario en castellano y escribe el material del alumnado en
  catalán.
- Responde de forma breve y directa. No añadas preámbulos ni
  metaexplicaciones al material.
- El usuario es quien usa `editor.py`; no lo abras ni lo controles por él.
- No uses subagentes por defecto. Si hacen falta, da un encargo preciso y
  revisa siempre el resultado.
- Si una aportación del usuario parece obsoleta o incorrecta, explica el
  motivo. Si el cambio sería grande, muestra las dos alternativas antes de
  sustituirla.
