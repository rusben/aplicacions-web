Aplicacions Web

RAX · HTML i CSS

Què és aquest RA

Material complementari: el currículum oficial del mòdul 0228 no inclou HTML ni CSS, però entendre'ls ajuda a personalitzar qualsevol gestor de continguts. Per això es treballen a part, sense barrejar-los amb els resultats d'aprenentatge oficials.

El punt de partida és la teoria T1.2 del RA1, que presenta HTML i CSS. Aquí s'aprofundeix en la disposició de la pàgina i es fan webs completes.

Teoria

La disposició dels elements a la pàgina, després de la presentació de T1.2.

  • TX.1 Capses i disposició Model de capsa, position, Flexbox i Grid

Guies

El manual que necessites per publicar qualsevol de les activitats i pràctiques d'aquest RA.

  • GX.1 Guia: repositori i GitHub Pages Clonar per SSH i publicar-hi un web estàtic

Activitats

Webs estàtiques fetes a mà i publicades a GitHub Pages.

  • AX.1 Targeta Pokémon Donar estil només amb CSS
  • AX.2 Landing page Menú, imatge destacada, botó i peu
  • AX.3 Zoo interactiu Grid i Flexbox cara a cara

Pràctiques

Les dues pràctiques principals d'aquest RA: un web propi i, després, el disseny aplicat a una botiga virtual real.

  • PX.1 Pràctica: web HTML5 Tres pàgines semàntiques i adaptades al mòbil
  • PX.2 Pràctica: botigues virtuals Dues plataformes de comerç electrònic comparades
