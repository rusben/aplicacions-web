Requeriments i instal·lació

Abans d'instal·lar, mirar què demana cada gestor i què té el servidor. Després, instal·lar-ne un i veure com funciona per dins.

Què has de saber abans de començar

Teoria T1.3 (requeriments, sistemes lliures i propietaris, funcionament intern). Les guies G1.1, G1.2 i G1.3 són els manuals que consultaràs.

Compararàs els requeriments de tres gestors, comprovaràs si el teu servidor els compleix, instal·laràs WordPress i seguiràs una pàgina des de la base de dades fins al navegador. L'escriptori que prepares aquí és l'escriptori de proves de les activitats A1.3 a A1.6.

Un centre educatiu vol una web i dubta entre WordPress, Joomla i Drupal. També pregunta si la podria tenir al servidor Windows que ja fa servir la secretaria. Tu has de preparar la resposta tècnica.

Què has de fer

  1. Omple una taula de requeriments de WordPress, Joomla i Drupal amb la seva documentació oficial: PHP mínim i recomanat, base de dades, extensions de PHP, servidor web i reescriptura d'adreces. Posa l'enllaç d'on surt cada dada.
  2. Prepara l'escriptori, instal·la la pila LAMP i fes l'inventari del servidor. Afegeix a la taula una columna «El meu servidor» i marca què compleix.
  3. Explica en una segona taula què canviaria si l'escola ho instal·lés al seu Windows Server: servidor web, PHP, base de dades, enllaços amigables i cost.
  4. Instal·la WordPress a proves.internal i activa els enllaços permanents.
  5. Publica una entrada titulada «Hola des de la base de dades». Troba-la amb una consulta a MySQL i canvia-li el títol des de MySQL. Recarrega la pàgina i explica què ha passat.
  6. Passa les proves de funcionament de l'apartat de comprovació i guarda'n la sortida.

Consultes per al punt 5 (canvia el text pel teu):

SELECT ID, post_title, post_status FROM wp_posts
  WHERE post_type = 'post';
UPDATE wp_posts SET post_title = 'Títol canviat des de MySQL'
  WHERE ID = 5;

Dades de la font, no de memòria

Els requeriments canvien a cada versió. Una taula sense enllaços o copiada d'un article antic no serveix: cada dada ha de sortir de la documentació oficial i ha de dir de quina versió del gestor parla.

Mirar les taules del gestor

Entra a MySQL amb l'usuari del lloc i executa SHOW TABLES;. Hi veuràs on guarda WordPress les entrades, els usuaris, les opcions i els comentaris. Tot el que fas al tauler acaba en una d'aquestes taules.

Com sabràs que ho has fet bé

  • php -m mostra totes les extensions que la taula marca com a necessàries.
  • curl -I http://proves.internal/ respon 200 i curl -I http://proves.internal/wp-admin/ redirigeix a l'inici de sessió.
  • mysql -u provesuser -p provesdb -e "SHOW TABLES;" llista les taules wp_.
  • El títol canviat des de MySQL surt a la web sense tocar el tauler.

Si alguna cosa no va

L'instal·lador diu que falta una extensió de PHP

Causa El servidor no complia un requeriment de la teva taula.

Solució Instal·la el paquet php-… que falta, reinicia Apache i anota-ho a la taula.

L'UPDATE diu «0 rows affected»

Causa L'ID no és el de la teva entrada.

Solució Fes primer el SELECT i copia l'ID que surt.

Què has d'entregar

Un repositori a GitHub amb un README.md que tingui les dues taules, la sortida de l'inventari, captures de la instal·lació i del canvi de títol, i la sortida de les comprovacions.
