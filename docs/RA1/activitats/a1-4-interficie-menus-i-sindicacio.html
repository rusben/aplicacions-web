Interfície, menús i sindicació

Del lloc per defecte a un web amb identitat pròpia, navegació clara i fils RSS.

Què has de saber abans de començar

Teories T1.2 (CSS addicional) i T1.3 (temes, menús, ginys i sindicació). La guia G1.3, apartats d'aparença, identitat, menús, ginys, sindicació i extensions, és el manual que consultaràs.

Personalitzaràs la interfície del gestor sense tocar-ne els fitxers, configuraràs els menús i els mòduls que el lloc necessita i publicaràs i consumiràs fils RSS.

Amb què treballaràs

L'escriptori de proves de l'A1.2, amb WordPress a proves.internal. El lloc serà el web de notícies d'un club esportiu: té seccions de Competició i Escola, i vol que els socis rebin les novetats sense entrar-hi.

Què has de fer

  1. Fes una captura de la portada abans de començar: és la comparació final.
  2. Identitat: títol, descripció, icona del lloc, zona horària i format de data.
  3. Aparença: activa un tema diferent del de per defecte, canvia'n la paleta de colors i la tipografia des de l'editor del lloc i afegeix una regla de CSS addicional pròpia.
  4. Contingut: dues categories, quatre entrades repartides i les pàgines «El club» i «Contacte». Portada estàtica i pàgina d'entrades a part.
  5. Menús: un menú principal amb les pàgines i les dues categories, amb un submenú, i un menú de peu.
  6. Ginys: al peu o a la barra lateral, un cercador, les últimes entrades i un bloc RSS amb les notícies d'un altre web.
  7. Mòduls: instal·la i configura una extensió que afegeixi una funció útil al club (formulari, calendari d'esdeveniments, galeria…). Esborra les que vinguin de sèrie i no facis servir.
  8. Sindicació: fes que el fil porti només un resum, comprova el fil general i el d'una categoria, i subscriu-t'hi des d'un lector de notícies.

Personalitzar sense tocar el tema

No editis els fitxers del tema: la primera actualització esborraria els canvis. Tot el que facis ha de viure a l'editor del lloc, al CSS addicional o a la configuració d'una extensió.

Què hi ha dins d'un fil

Obre /feed/ al navegador o amb curl. Cada <item> és una entrada amb títol, enllaç, data i resum. Un lector de notícies només fa això: demanar el fil de tant en tant i avisar quan hi ha un element nou.

Com sabràs que ho has fet bé

  • curl -s http://proves.internal/feed/ | grep -c '<item>' dona el nombre d'entrades publicades.
  • curl -s http://proves.internal/category/escola/feed/ només porta entrades d'aquella categoria.
  • Canviar temporalment de tema manté les entrades, les pàgines i els menús.
  • sudo -u www-data wp plugin list no mostra cap extensió inactiva.
  • Una entrada nova apareix al lector de notícies sense entrar al web.

Si alguna cosa no va

El fil d'una categoria dona 404

Causa L'adreça no coincideix amb el nom curt de la categoria, o els enllaços permanents no estan actius.

Solució Copia el nom curt d'Entrades → Categories i revisa els enllaços permanents.

El CSS addicional no s'aplica

Causa El selector no coincideix amb l'HTML que genera el tema.

Solució Inspecciona l'element amb F12 i copia'n la classe, com explica T1.2.

Què has d'entregar

Un repositori a GitHub amb un README.md que tingui les captures d'abans i després, l'estructura dels menús, el CSS addicional comentat, l'extensió triada amb la seva configuració, la sortida de les comprovacions i una captura del lector de notícies.

Respon-hi també: quina diferència hi ha entre canviar l'aspecte amb el tema i fer-ho amb CSS addicional, i quan triaries cada opció?
