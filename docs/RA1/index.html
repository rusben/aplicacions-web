Aplicacions Web

RA1 · Instal·lació de gestors de continguts

Teoria

Expliquen com funciona una aplicació web i un gestor de continguts, sense dependre de cap producte.

  • T1.1 Com funciona una aplicació web Client i servidor, URL, HTTP, estàtic i dinàmic
  • T1.2 HTML i CSS Presentació: el que genera el gestor i el que es personalitza
  • T1.3 Gestors de continguts Requeriments, funcionament, interfície, mòduls i sindicació
  • T1.4 Usuaris, grups i rols Qui pot fer què, i regles d'accés als fòrums
  • T1.5 Mantenir un gestor de continguts Actualitzar, protegir, copiar i provar

Guies

Els manuals pas a pas que tindràs oberts mentre fas les activitats i la pràctica.

  • G1.1 Guia: l'entorn de laboratori Un escriptori Ubuntu 26.04 LTS a IsardVDI
  • G1.2 Guia: pila LAMP i host virtual Apache, MySQL i PHP a Ubuntu 26.04
  • G1.3 Guia: WordPress Instal·lació, usuaris, aparença, menús, fòrums i manteniment
  • G1.4 Guia: migrar WordPress a un allotjament Còpia, restauració i canvi d'adreça

Activitats

Exercicis curts per assajar cada idea abans de la pràctica. L'A1.1 es fa en un escriptori nou; de l'A1.2 a l'A1.6 es treballa sobre el mateix escriptori de proves d'IsardVDI, amb Ubuntu 26.04 LTS.

  • A1.1 Estàtic i dinàmic Pila LAMP, PHP i un mur amb base de dades
  • A1.2 Requeriments i instal·lació Comparar gestors, comprovar el servidor i instal·lar-ne un
  • A1.3 Usuaris, grups i rols La redacció d'una revista digital
  • A1.4 Interfície, menús i sindicació Identitat, tema, menús, ginys i fils RSS
  • A1.5 Fòrum amb regles d'accés Fòrums públics, privats i ocults, i qui hi entra
  • A1.6 Actualitzar, protegir i copiar Manteniment, seguretat, còpia, restauració i proves

Pràctica

Instal·lació i configuració completa d'un gestor de continguts en un escriptori nou. És la pràctica principal del RA i la part que més pesa a la nota.

  • P1.1 Pràctica: portal amb WordPress Instal·lar, configurar, protegir, copiar i provar
