Guia: WordPress

De la carpeta buida a un lloc amb usuaris, grups, menús, fòrums, còpies i estil propi.

Què hi ha en aquesta guia

Documentació oficial: wordpress.org/documentation · ca.wordpress.org

  • Punt de partida: pila LAMP i host virtual fets amb G1.2. Aquí el lloc es diu wordpress.internal, la base de dades wpdb i l'usuari wpuser.
  • Cobreix instal·lació, enllaços permanents, usuaris i grups, aparença, menús i sindicació, extensions, idiomes, fòrums, WP-CLI, seguretat, còpies i proves.
  • WordPress recomana PHP 8.3 o superior, MySQL 8.0 o superior i HTTPS; Ubuntu 26.04 compleix les dues primeres. Els requeriments actualitzats són a wordpress.org/about/requirements.

Instal·lar WordPress

  1. Descarrega i descomprimeix l'última versió al DocumentRoot:

    cd /tmp
wget https://wordpress.org/latest.zip
sudo unzip -q latest.zip -d /tmp
sudo cp -a /tmp/wordpress/. /var/www/wordpress.internal/
sudo rm -f /var/www/wordpress.internal/index.html

  2. Dona els fitxers a Apache:

    sudo chown -R www-data:www-data /var/www/wordpress.internal

  3. Obre http://wordpress.internal, tria Català i omple les dades de la base de dades:

    CampValor
    Nom de la base de dadeswpdb
    Nom d'usuariwpuser
    ContrasenyaLa que vas posar a MySQL
    Servidorlocalhost
    Prefix de les tauleswp_, o un altre si comparteixes base

  4. Posa el títol del lloc i l'administrador. Evita admin com a nom d'usuari i fes servir una contrasenya llarga.

  5. Entra al tauler a http://wordpress.internal/wp-admin.

Enllaços permanents

  1. Comprova que rewrite està actiu i que el host virtual té AllowOverride All (G1.2):

    apache2ctl -M | grep rewrite
rewrite_module (shared)

  2. A Configuració → Enllaços permanents, tria «Nom de l'entrada» i desa.

  3. Comprova el .htaccess que ha escrit WordPress:

    cat /var/www/wordpress.internal/.htaccess
# BEGIN WordPress
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteBase /
RewriteRule ^index\.php$ - [L]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule . /index.php [L]
</IfModule>
# END WordPress

  4. Obre una entrada: l'adreça ha de ser /nom-de-l-entrada/ i no ?p=123.

Usuaris i rols

  1. A Usuaris → Afegeix, crea un compte per persona amb nom d'usuari, correu i contrasenya.

  2. Tria el rol al desplegable. Els rols i què pot fer cadascun són a T1.4.

  3. Prova cada rol iniciant sessió en una finestra privada del navegador.

  4. Decideix qui es pot registrar a Configuració → General: casella «Qualsevol es pot registrar» i «Rol per defecte dels usuaris nous». Deixa-la desmarcada si no cal.

Rols personalitzats i grups

WordPress porta cinc rols i cap grup. Per a totes dues coses calen extensions.

  1. Instal·la User Role Editor. A Usuaris → User Role Editor, clica Add Role, posa-li un identificador (corrector) i fes-lo a partir d'un rol existent amb «Make copy of».

  2. Ajusta les capacitats del rol nou: marca o desmarca publish_posts, edit_others_posts, upload_files… i desa amb Update.

  3. Instal·la Groups. A Grups → Grups, crea un grup (Redacció). Afegeix-hi usuaris des de la llista d'usuaris, amb l'acció en bloc per afegir al grup.

  4. Restringeix un contingut al grup: a l'editor de l'entrada o pàgina, al quadre Groups, tria el grup que la pot llegir i desa.

  5. Comprova-ho en una finestra privada: sense sessió, o amb un usuari de fora del grup, el contingut no es veu.

Aparença

  1. A Aparença → Temes → Afegeix un tema, busca'n un i activa'l.

  2. A Aparença → Editor, edita la capçalera, el peu, els menús i la plantilla de la portada.

  3. A Configuració → Lectura, tria si la portada és una pàgina estàtica o les últimes entrades.

  4. Afegeix el CSS propi a Aparença → Editor → Estils → CSS addicional. Sobreviu a les actualitzacions del tema:

    .wp-block-site-title a {
  color: #1d4e89;
  text-transform: uppercase;
}

Identitat, menús, ginys i sindicació

  1. Identitat del lloc: a Configuració → General, títol, descripció curta, icona del lloc, idioma i zona horària.

  2. Menús: a Aparença → Editor → Navegació, crea el menú principal i afegeix-hi pàgines, categories i enllaços. Crea'n un altre per al peu i col·loca'l al patró del peu.

  3. Ginys: a Aparença → Editor → Patrons, edita el peu o la barra lateral i afegeix-hi blocs: Cerca, Últimes entrades, Categories o RSS, que mostra les entrades d'un altre web.

  4. Sindicació: a Configuració → Lectura, tria quantes entrades surten al fil i si porten el text complet o un resum.

  5. Comprova els fils des de la terminal:

    curl -s http://wordpress.internal/feed/ | grep -c '<item>'
curl -s http://wordpress.internal/category/noticies/feed/ | head -5

Extensions

  1. A Extensions → Afegeix, busca l'extensió, clica Instal·la i després Activa.

  2. Configura-la al menú que hagi afegit.

  3. Esborra les que no facis servir: desactivar no n'hi ha prou.

Lloc en diversos idiomes amb Polylang

  1. Instal·la i activa Polylang.

  2. A Idiomes, afegeix català, castellà i anglès. El primer és l'idioma per defecte.

  3. Edita una entrada: a la columna d'idioma, el + crea la traducció enllaçada.

  4. Afegeix el selector d'idioma al menú des de l'editor del lloc.

Fòrums amb bbPress

  1. Instal·la i activa bbPress. Apareix el menú Fòrums al tauler.

  2. Crea un fòrum a Fòrums → Afegeix i tria'n la visibilitat: públic, privat (només usuaris registrats) o ocult (només moderadors).

  3. Fixa les regles d'accés a Configuració → Fòrums: quin rol de fòrum rep automàticament qui es registra i si es permet publicar sense compte.

  4. Dona un rol de fòrum a cada usuari des del seu perfil, i afegeix la pàgina del fòrum al menú.

Administrar-lo amb WP-CLI

Documentació: WP-CLI Commands. Serveix per fer des de la terminal el que es fa al tauler, i per repetir-ho sense errors.

  1. Instal·la WP-CLI:

    curl -O https://raw.githubusercontent.com/\
wp-cli/builds/gh-pages/phar/wp-cli.phar
chmod +x wp-cli.phar
sudo mv wp-cli.phar /usr/local/bin/wp

  2. Executa'l com a www-data des de la carpeta del lloc, perquè els fitxers no canviïn de propietari:

    cd /var/www/wordpress.internal
sudo -u www-data wp core version
sudo -u www-data wp plugin list

  3. Consulta què cal actualitzar i aplica-ho:

    sudo -u www-data wp core check-update
sudo -u www-data wp plugin list --update=available
sudo -u www-data wp plugin update --all
sudo -u www-data wp theme update --all
sudo -u www-data wp core update

  4. Comprova que el nucli no s'ha modificat:

    sudo -u www-data wp core verify-checksums
Success: WordPress installation verifies against checksums.

Seguretat i manteniment

  1. Obre Eines → Salut del lloc i resol els avisos crítics.

  2. A Tauler → Actualitzacions, aplica el nucli, els temes i les extensions pendents. Abans, fes una còpia.

  3. Activa les actualitzacions automàtiques a la llista d'extensions i de temes.

  4. Tanca el que no cal: esborra temes i extensions inactius, desmarca el registre obert si no el necessites i, a Configuració → Discussió, fes que els comentaris s'hagin d'aprovar.

  5. Desactiva l'editor de fitxers del tauler, que permetria canviar codi PHP des del navegador. Afegeix a wp-config.php, abans de la línia «That's all, stop editing»:

    define( 'DISALLOW_FILE_EDIT', true );

  6. Contrasenyes d'aplicació: al perfil de cada usuari, revoca les que no es facin servir.

  7. Protegeix wp-config.php: només l'ha de poder llegir Apache.

    sudo chmod 640 /var/www/wordpress.internal/wp-config.php

  8. Fes una còpia completa: base de dades i fitxers.

    sudo mysqldump --single-transaction wpdb > wpdb-$(date +%F).sql
sudo tar -czf wp-fitxers-$(date +%F).tar.gz \
  -C /var/www wordpress.internal

  9. Treu la còpia del servidor, per exemple cap a un altre escriptori:

    scp wpdb-*.sql wp-fitxers-*.tar.gz usuari@192.168.120.46:~/copies/

Restaurar una còpia

  1. Recupera els fitxers de la còpia. Si la carpeta del lloc encara existeix, mou-la abans:

    sudo mv /var/www/wordpress.internal /var/www/wordpress.vell
sudo tar -xzf wp-fitxers-DATA.tar.gz -C /var/www
sudo chown -R www-data:www-data /var/www/wordpress.internal

  2. Recupera la base de dades. El bolcat substitueix les taules que ja hi són:

    sudo mysql wpdb < wpdb-DATA.sql

  3. Passa les proves de funcionament i, si tot va bé, esborra /var/www/wordpress.vell.

Proves de funcionament

  • La portada i /wp-admin carreguen sense avisos.
  • Una entrada s'obre pel seu enllaç permanent, sense ?p=.
  • Es pot pujar una imatge a Mèdia.
  • Un usuari col·laborador pot escriure però no publicar.
  • El formulari de contacte envia i el canvi d'idioma funciona.
  • Un contingut restringit a un grup no es veu des d'una finestra privada.
  • El fil /feed/ mostra les últimes entrades.
  • Salut del lloc no té avisos crítics i wp core verify-checksums passa.

Criteris professionals

  • Cap usuari anomenat admin i contrasenyes llargues.
  • Temes i extensions només del directori oficial.
  • CSS propi al CSS addicional, mai als fitxers del tema.
  • Còpia abans de cada actualització.

Errors habituals

Error establint la connexió amb la base de dades

Causa Dades incorrectes a l'assistent o a wp-config.php.

Solució Prova l'usuari amb mysql -u wpuser -p wpdb.

Totes les pàgines menys la portada donen 404

Causa Enllaços permanents sense rewrite o sense AllowOverride All.

Solució Activa el mòdul, revisa el host virtual i torna a desar els enllaços permanents.

WordPress demana dades d'FTP per instal·lar extensions

Causa Apache no pot escriure als fitxers.

Solució Torna a fer el chown a www-data. Com a últim recurs, afegeix define('FS_METHOD', 'direct'); a wp-config.php.

«El fitxer pujat supera la directiva upload_max_filesize»

Causa El límit de PHP és massa baix.

Solució Puja'l com explica G1.2 i reinicia Apache.
