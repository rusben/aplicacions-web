Guia: correu web amb Roundcube

Instal·lar el client web, connectar-lo al servidor de correu i deixar-lo a punt per a l'usuari.

Què hi ha en aquesta guia

Documentació oficial: Roundcube · wiki del projecte

  • Punt de partida: el servidor de correu de G5.1 a la mateixa màquina, i la pila LAMP de G1.2.
  • Resultat: http://correu.internal/roundcube, amb els comptes del servidor de correu.
  • Cobreix la instal·lació, la connexió amb IMAP i SMTP, les preferències de l'usuari, els filtres i la llibreta d'adreces.

Instal·lar Roundcube

  1. Instal·la els paquets. L'assistent demana si vol configurar la base de dades: respon que sí i apunta la contrasenya.

    sudo apt update
sudo apt install -y roundcube roundcube-mysql

  2. Comprova que Apache ja el serveix: el paquet deixa la configuració activada.

    ls /etc/apache2/conf-enabled/ | grep roundcube
sudo apache2ctl configtest
sudo systemctl reload apache2

  3. Obre http://correu.internal/roundcube: ha de sortir la pantalla d'inici de sessió.

Connectar-lo amb el servidor de correu

  1. Edita la configuració del client:

    sudo nano /etc/roundcube/config.inc.php

  2. Digues a quin servidor IMAP i SMTP s'ha de connectar i quin domini s'afegeix a l'usuari:

    $config['imap_host'] = 'localhost:143';
$config['smtp_host'] = 'localhost:25';
$config['mail_domain'] = 'correu.internal';
$config['product_name'] = 'Correu del centre';

  3. Inicia sessió amb un dels comptes creats a G5.1: el nom d'usuari i la contrasenya del sistema.

  4. Envia un missatge a un altre compte del servidor i comprova que arriba a la bústia.

  5. Si alguna cosa falla, mira el registre del client i el del correu alhora:

    sudo tail -f /var/log/roundcube/errors.log /var/log/mail.log

Deixar-lo a punt per a l'usuari

  1. Identitat i signatura: a Configuració → Identitats, posa el nom que veuran els destinataris i una signatura.

  2. Carpetes: a Configuració → Carpetes, crea les que calguin i marca quines es veuen a la llista.

  3. Preferències: idioma, zona horària, com es marquen els missatges com a llegits i què passa en esborrar.

  4. Llibreta d'adreces: afegeix contactes i grups des de Contactes; es poden importar i exportar en format .vcf.

  5. Filtres (cal el mòdul del servidor):

    sudo apt install -y dovecot-sieve dovecot-managesieved

    Afegeix managesieve a la llista de connectors de la configuració del client i crea una regla a Configuració → Filtres, per exemple moure a una carpeta tot el que porti una paraula a l'assumpte.

Compte El client no té comptes propis: no s'hi crea cap usuari. Qui pot entrar-hi és qui té compte al servidor de correu.

Comprovació de conjunt

  • Cada compte del servidor de correu pot iniciar sessió al client web.
  • Un missatge enviat des del client arriba a la bústia de l'altre usuari i es veu al seu correu web.
  • El missatge enviat queda a la carpeta d'elements enviats.
  • Un missatge enviat des del terminal amb mail apareix al client web.
  • El filtre mou a la carpeta esperada un missatge de prova.
  • Un compte desactivat al sistema ja no pot iniciar sessió.

Criteris professionals

  • Els comptes es gestionen al servidor de correu, no al client.
  • HTTPS abans de donar-lo a ningú: hi viatgen contrasenyes.
  • Només els connectors que facin falta.
  • Prova sempre amb dos comptes: enviar-te un correu a tu mateix amaga la meitat dels problemes.
  • Mira els dos registres alhora, el del client i el del correu.

Errors habituals

«Connexió al servidor fallida»

Causa imap_host apunta a un servidor o a un port on no hi ha ningú.

Solució Comprova amb ss -tlnp que el 143 escolta i revisa la configuració.

Entra però la safata és buida i el terminal diu que hi ha missatges

Causa Dovecot busca les bústies en un altre lloc.

Solució Revisa mail_location a G5.1.

No deixa enviar: «relay access denied»

Causa S'envia a un domini que el servidor no serveix.

Solució Al laboratori, envia només a adreces internes.

No surt la pestanya de filtres

Causa Falta el connector o el mòdul del servidor.

Solució Instal·la els paquets del pas 5 i afegeix el connector a la configuració.
