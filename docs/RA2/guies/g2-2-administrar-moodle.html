Guia: administrar Moodle

Lloc, usuaris, cursos, inscripcions, aspecte, còpies, informes i seguretat, des del navegador.

Què hi ha en aquesta guia

Documentació oficial: docs.moodle.org

  • Punt de partida: Moodle instal·lat amb G2.1 i sessió iniciada com a administrador.
  • Les rutes són les del menú en català: Administració del lloc és a la barra superior.
  • Els noms dels menús poden variar lleugerament entre versions; si no trobes una opció, fes servir el cercador de l'administració.

Configuració inicial del lloc

  1. Perfil propi: menú d'usuari → Perfil → Edita el perfil; canvia correu, contrasenya i imatge.

  2. Nom i portada: Administració del lloc → General → Portada; nom llarg i curt.

  3. Portada només per a usuaris identificats: Administració del lloc → Seguretat → Normatives del lloc → Força els usuaris a identificar-se.

  4. Zona horària: Administració del lloc → General → Ubicació → Paràmetres d'ubicació; tria Europe/Madrid. Les dates d'entrega en depenen.

  5. Idioma: Administració del lloc → General → Idioma → Paquets d'idioma; instal·la'l i tria'l com a predeterminat.

  6. Contrasenyes: Seguretat → Normatives del lloc → Normativa de contrasenyes; 8 caràcters, amb dígits, minúscules i majúscules.

Usuaris

  1. Un compte a mà: Administració del lloc → Usuaris → Comptes → Afegeix un usuari, amb autenticació Comptes manuals.

  2. Molts comptes d'un CSV: Usuaris → Comptes → Carrega usuaris. El fitxer ha de ser UTF-8 i tenir aquestes capçaleres:

    username,firstname,lastname,email,password
blobesponja,Blob,Esponja,blobesponja@exemple.internal,Abc123!x
jsongoku,JSON,Goku,jsongoku@exemple.internal,Abc123!x
ritahardware,Rita,Hardware,ritahardware@exemple.internal,Abc123!x

  3. Accions en bloc: Usuaris → Comptes → Accions sobre usuaris en bloc; filtra, selecciona i tria Suprimeix, Força el canvi de contrasenya…

  4. Camps de perfil propis: Usuaris → Comptes → Camps del perfil de l'usuari.

Cursos i inscripcions

  1. Categoria: Administració del lloc → Cursos → Gestiona cursos i categories → Crea una categoria.

  2. Curs: a la categoria, Crea un curs; nom, nom curt, format Temes i nombre de seccions.

  3. Mètodes d'inscripció: dins del curs, Participants → Mètodes d'inscripció. Activa o desactiva Inscripció manual, Autoinscripció i Accés de convidats.

  4. Matricular: Participants → Inscriu usuaris; tria les persones i el rol.

  5. Afegir contingut: activa el Mode d'edició i, a cada secció, Afegeix una activitat o un recurs.

  6. Importar d'un altre curs: Més → Reutilitza el curs → Importa.

Qualificacions, insígnies i qüestionaris

  1. Qualificador: al curs, Qualificacions → Configuració del qualificador; tria l'agregació, per exemple Mitjana de qualificacions.

  2. Insígnia: Més → Insígnies → Afegeix una insígnia; defineix el criteri, activa-la i atorga-la.

  3. Banc de preguntes: Més → Banc de preguntes; crea categories i preguntes, o importa-les en format GIFT.

  4. Qüestionari: afegeix l'activitat i, a Preguntes, Afegeix → del banc de preguntes.

Aspecte

  1. Instal·lar un tema: Administració del lloc → Connectors → Instal·la connectors; puja el ZIP del directori oficial.

  2. Triar-lo: Aparença → Temes.

  3. Logotip i colors: Aparença → Logotips i els paràmetres del tema, com el color de marca de Boost.

  4. CSS propi: paràmetres del tema → SCSS en brut:

    .navbar { border-bottom: 4px solid #1d4e89; }

  5. Capçalera i peu: Aparença → Configuració addicional d'HTML.

Còpies

  1. Còpia d'un curs: Més → Reutilitza el curs → Còpia de seguretat; tria si inclou usuaris i descarrega el .mbz.

  2. Restaurar-la: Reutilitza el curs → Restaura; puja el .mbz i tria si va a un curs nou o existent.

  3. Còpies automàtiques: Administració del lloc → Cursos → Còpia de seguretat → Paràmetres de còpia automatitzada.

  4. Còpia del lloc des del terminal, amb Moodle en manteniment:

    sudo -u www-data php /var/www/moodle.internal/admin/cli/\
maintenance.php --enable
sudo mysqldump --single-transaction moodle > moodle-$(date +%F).sql
sudo tar -czf moodle-$(date +%F).tar.gz \
  /var/www/moodle.internal /var/moodledata
sudo -u www-data php /var/www/moodle.internal/admin/cli/\
maintenance.php --disable

Informes i seguretat

  1. Registres: Administració del lloc → Informes → Registres; filtra per curs, usuari, dia i acció.

  2. Ús d'un curs: al curs, Informes → Activitat del curs i Participació al curs.

  3. Bloquejar una IP: Administració del lloc → General → Seguretat → Blocador d'IP; escriu-la a Llista d'IP bloquejades.

  4. Comprovar el lloc: Informes → Comprovacions de seguretat; resol els Crític i Seriós.

Comprovació de conjunt

  • Un usuari del CSV inicia sessió i ha de canviar la contrasenya segons la normativa.
  • Un curs amb accés de convidats s'obre en una finestra privada sense iniciar sessió.
  • El .mbz d'un curs es restaura en un curs nou amb tot el contingut.
  • Els registres mostren l'accés de l'usuari de prova amb la seva IP.

Criteris professionals

  • Zona horària i normativa de contrasenyes, abans de crear cursos i comptes.
  • Usuaris en bloc amb CSV; elimina'ls en bloc quan acabin.
  • Blocar una IP de l'aula pot deixar fora tot el grup: comprova-ho abans.
  • Còpia del lloc abans d'instal·lar temes o connectors.

Errors habituals

La càrrega de CSV dona «Capçalera no vàlida»

Causa Una columna mal escrita o el fitxer no és UTF-8.

Solució Revisa les capçaleres exactes i desa en UTF-8 sense BOM.

Després de bloquejar una IP, ningú no pot entrar

Causa S'ha escrit a IP permeses, que deixa entrar només les de la llista.

Solució Des del servidor, buida el camp amb admin/cli/cfg.php o a la base de dades, i posa l'adreça a IP bloquejades.

La tasca tanca una hora abans

Causa La zona horària del lloc o de l'usuari no és la correcta.

Solució Revisa els paràmetres d'ubicació i el perfil.
