Guia: instal·lar Moodle

Moodle 5.2 amb Apache, MySQL i PHP, l'arrel a public i el cron en marxa.

Què hi ha en aquesta guia

Documentació oficial: Installing Moodle · requeriments de Moodle 5.2

  • Resultat: Moodle 5.2 a http://moodle.internal, amb les dades a /var/moodledata.
  • La pila i el host virtual segueixen G1.2, amb els canvis que s'indiquen.
Primer, els requeriments Moodle és exigent amb la versió de PHP. Abans de començar, mira la pàgina de requeriments de la versió que instal·laràs i compara-la amb el que porta l'escriptori (php -v). Si la teva versió de Moodle encara no admet el PHP d'Ubuntu 26.04, fes l'escriptori amb Ubuntu 24.04 LTS, que porta PHP 8.3, i canvia 8.5 per 8.3 a les rutes d'aquesta guia.

Preparar el servidor

  1. Instal·la la pila amb les extensions de PHP que demana Moodle:

    sudo apt update
sudo apt install -y apache2 mysql-server libapache2-mod-php \
  php-mysql php-xml php-mbstring php-curl php-zip php-gd \
  php-intl php-soap

  2. Puja max_input_vars a 5000, que és el mínim de Moodle:

    echo 'max_input_vars = 5000' | \
  sudo tee /etc/php/8.5/apache2/conf.d/99-moodle.ini
sudo systemctl restart apache2

  3. Crea la base de dades i l'usuari:

    sudo mysql
    CREATE DATABASE moodle
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_bin;
CREATE USER 'moodleuser'@'localhost' IDENTIFIED BY 'Canvia-la-2026';
GRANT ALL PRIVILEGES ON moodle.* TO 'moodleuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Posar-hi el codi i el directori de dades

  1. Descarrega Moodle 5.2 i descomprimeix-lo:

    cd /tmp
wget https://download.moodle.org/download.php/direct/stable502/\
moodle-latest-502.tgz
sudo tar -xzf moodle-latest-502.tgz -C /var/www
sudo mv /var/www/moodle /var/www/moodle.internal

  2. Crea el directori de dades, fora de /var/www:

    sudo mkdir /var/moodledata
sudo chown www-data:www-data /var/moodledata
sudo chmod 770 /var/moodledata

  3. Deixa que l'instal·lador escrigui config.php:

    sudo chown -R www-data:www-data /var/www/moodle.internal

Host virtual amb l'arrel a public

  1. Crea el lloc:

    sudo nano /etc/apache2/sites-available/moodle.internal.conf
    <VirtualHost *:80>
    ServerName moodle.internal
    DocumentRoot /var/www/moodle.internal/public

    <Directory /var/www/moodle.internal/public>
        AllowOverride None
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/moodle.internal_error.log
    CustomLog ${APACHE_LOG_DIR}/moodle.internal_access.log combined
</VirtualHost>

  2. Activa'l i afegeix el nom a /etc/hosts:

    sudo a2ensite moodle.internal.conf
sudo apache2ctl configtest
sudo systemctl reload apache2
echo '127.0.0.1 moodle.internal' | sudo tee -a /etc/hosts

Instal·lador web

  1. Obre http://moodle.internal i tria l'idioma Català.

  2. Confirma les rutes: adreça web http://moodle.internal, directori de dades /var/moodledata.

  3. Tria el controlador MySQL millorat (natiu/mysqli) i escriu localhost, moodle, moodleuser i la contrasenya.

  4. Revisa la comprovació de l'entorn: tot el que és obligatori ha de sortir en verd. Si falta una extensió, instal·la el paquet php-…, reinicia Apache i torna a carregar.

  5. Espera que creï les taules i omple el compte d'administrador i el nom del lloc.

Cron i permisos finals

  1. Programa el cron cada minut amb l'usuari d'Apache:

    sudo crontab -u www-data -e
    * * * * * /usr/bin/php /var/www/moodle.internal/admin/cli/cron.php

  2. Torna el codi a root: Apache només ha de poder escriure a moodledata:

    sudo chown -R root:root /var/www/moodle.internal
sudo chmod 644 /var/www/moodle.internal/config.php

  3. Comprova el cron executant-lo a mà una vegada:

    sudo -u www-data /usr/bin/php \
  /var/www/moodle.internal/admin/cli/cron.php | tail -3
Cron completed at ...

Comprovació de conjunt

  • http://moodle.internal mostra la portada i es pot iniciar sessió.
  • http://moodle.internal/config.php no ensenya res: config.php és fora de l'arrel web.
  • Administració del lloc → Servidor → Entorn no té cap requisit obligatori en vermell.
  • Administració del lloc → Notificacions no avisa que el cron no s'executa.

Criteris professionals

  • moodledata fora de /var/www, amb permisos 770.
  • Codi propietat de root un cop instal·lat.
  • Un usuari de base de dades només per a Moodle.
  • Actualitza Moodle dins de la mateixa branca (5.2.x) quan surtin versions de seguretat.

Errors habituals

L'entorn diu que la versió de PHP no és compatible

Causa La versió de Moodle que has baixat no admet el PHP de l'escriptori.

Solució Refés l'escriptori amb Ubuntu 24.04 LTS (PHP 8.3) o baixa la versió de Moodle que sí que l'admet. Comprova-ho sempre abans d'instal·lar.

«max_input_vars must be at least 5000»

Causa El fitxer de conf.d no s'ha llegit.

Solució Comprova que és a apache2/conf.d (no a cli) i reinicia Apache.

L'instal·lador no pot escriure config.php

Causa La carpeta del codi no és de www-data.

Solució Fes el chown temporal o copia el contingut que mostra a config.php a mà.

Es veu una llista de carpetes

Causa El DocumentRoot no acaba en /public.

Solució Corregeix-lo i recarrega Apache.
