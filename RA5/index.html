Aplicacions Web

RA5 · Instal·lació d'aplicacions web d'escriptori

Teoria

Què són les aplicacions web d'escriptori, com funciona el correu per dins i com s'organitza una agenda compartida.

  • T5.1 Aplicacions web d'escriptori Correu, agenda i contactes al navegador; client i servidor
  • T5.2 Com viatja un correu SMTP, IMAP i POP3, ports i bústies Maildir
  • T5.3 Calendaris, contactes i tasques CalDAV, cites, convidats, disponibilitat i sincronització

Guies

Els manuals pas a pas que tindràs oberts mentre fas les activitats i la pràctica.

  • G5.1 Guia: servidor de correu intern Postfix, Dovecot, bústies Maildir i comptes
  • G5.2 Guia: correu web amb Roundcube Instal·lació, connexió amb el servidor, filtres i contactes
  • G5.3 Guia: calendari, contactes i tasques web Calendaris compartits, convidats i sincronització

Activitats

Exercicis curts per assajar cada idea abans de la pràctica. L'A5.1 prepara l'escriptori que fan servir l'A5.2 i l'A5.3.

  • A5.1 Bústies al servidor Servidor de correu, comptes, àlies i proves al terminal
  • A5.2 Correu web Instal·lar el client, integrar-lo i verificar l'accés
  • A5.3 Agenda, contactes i tasques Calendaris compartits, convidats i sincronització

Pràctica

L'escriptori web sencer d'una organització en un escriptori nou, amb els manuals escrits. És la pràctica principal del RA i la part que més pesa a la nota.

  • P5.1 Pràctica: l'escriptori web de l'organització Correu, correu web i agenda, amb comptes, còpies i proves
