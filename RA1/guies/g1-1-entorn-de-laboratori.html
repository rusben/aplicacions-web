Guia: l'entorn de laboratori

On instal·laràs les aplicacions: un escriptori Ubuntu 26.04 LTS a IsardVDI.

Què hi ha en aquesta guia

Documentació oficial: IsardVDI · Ubuntu Server

  • Crear un escriptori virtual nou a IsardVDI amb Ubuntu 26.04 LTS.
  • Deixar-lo a punt: sistema actualitzat, nom de màquina, zona horària i accés per SSH.
  • Resultat: un servidor amb IP on instal·lar la pila LAMP de G1.2.

Les peces d'IsardVDI

PeçaQuè és
EscriptoriLa teva màquina virtual. Es crea, s'engega, s'atura i s'esborra des del navegador
PlantillaModel del qual surten els escriptoris; el professorat en publica una d'Ubuntu 26.04 LTS
MaquinariCPU, memòria i disc de l'escriptori, dins de la quota que tinguis
XarxaInterfícies de l'escriptori: la de sortida a Internet i les que hagi definit el centre
VisorCom veus la pantalla: al mateix navegador, amb el client SPICE o amb RDP

Cada activitat indica si parteix d'un escriptori nou o de l'escriptori de proves que ja tens. La pràctica sempre es fa en un escriptori nou.

Crear l'escriptori

  1. Entra a IsardVDI amb el compte del centre i ves a Escriptoris.

  2. Clica «Nou escriptori» i posa-li un nom que digui què és: p1-1-wordpress millor que prova2.

  3. Tria la plantilla Ubuntu 26.04 LTS que indiqui el professorat.

  4. Revisa el maquinari i les xarxes a les opcions avançades. Per a una pila LAMP en tens prou amb 2 vCPU i 4 GB de memòria.

  5. Engega'l i obre'l amb el visor del navegador. Inicia sessió amb l'usuari de la plantilla.

Deixar el sistema a punt

  1. Actualitza el sistema i reinicia si ho demana:

    sudo apt update && sudo apt upgrade -y
cat /etc/os-release | grep PRETTY
PRETTY_NAME="Ubuntu 26.04 LTS"

  2. Posa un nom de màquina propi. Surt al prompt i a les captures, i evita confusions entre escriptoris:

    sudo hostnamectl set-hostname wp-cognom
hostnamectl --static
wp-cognom

  3. Ajusta la zona horària: les dates de les entrades i dels registres en depenen.

    sudo timedatectl set-timezone Europe/Madrid
timedatectl | grep "Time zone"

  4. Consulta la IP de cada interfície:

    ip -brief a
lo      UNKNOWN  127.0.0.1/8
enp1s0  UP       192.168.120.45/22

Entrar-hi per SSH

  1. Instal·la i activa el servidor SSH:

    sudo apt install -y openssh-server
systemctl is-active ssh
active

  2. Connecta-t'hi des d'un altre escriptori teu que sigui a la mateixa xarxa, o des de casa si el centre t'ha donat accés per VPN:

    ssh usuari@192.168.120.45

  3. Treballa des de la terminal SSH: pots copiar i enganxar les ordres de les guies sense passar pel visor.

El cicle de vida de l'escriptori

VullA IsardVDI
TreballarEngega l'escriptori i obre el visor
PlegarApaga des del sistema (sudo poweroff) o amb el botó d'aturar
Canviar memòria o xarxesAmb l'escriptori aturat, edita'l
Començar de zeroEsborra l'escriptori i crea'n un de nou des de la plantilla

El disc de l'escriptori es conserva quan l'atures. El que es perd en esborrar-lo no es recupera: abans, fes la còpia de l'aplicació com explica G1.3.

Com saber que l'entorn està a punt

  • hostnamectl --static mostra el teu nom de màquina.
  • ip -brief a mostra una IP a la interfície de xarxa.
  • ping -c 2 ubuntu.com respon: l'escriptori surt a Internet.
  • Des d'un altre equip, ssh usuari@IP entra i sudo -v funciona.

Criteris professionals

  • Un escriptori per aplicació: WordPress, Moodle i Nextcloud no comparteixen màquina.
  • Noms que diguin què és cada escriptori i cada màquina.
  • Atura l'escriptori quan acabis: consumeix quota encara que no el miris.
  • Canvia la contrasenya de l'usuari de la plantilla si l'escriptori és accessible per xarxa.

Errors habituals

No puc crear més escriptoris

Causa Has arribat a la quota d'escriptoris o de disc.

Solució Esborra els escriptoris d'activitats ja entregades.

El visor no s'obre

Causa El client SPICE o RDP no està instal·lat a l'equip on ets.

Solució Tria el visor al navegador, que no necessita res.

No arribo a l'escriptori per SSH

Causa L'altre equip no és a la mateixa xarxa o fas servir la IP de la interfície equivocada.

Solució Revisa les xarxes dels dos escriptoris i la sortida de ip -brief a.

apt diu que no queda espai

Causa El disc de l'escriptori és petit.

Solució Mira-ho amb df -h / i neteja amb sudo apt clean; si no n'hi ha prou, demana més disc.
